## Ecommerce projects

Existing storefront projects: **Presura** and **Valenor**.

## Presura — Shopify Storefront

A live Shopify storefront built for the Ghana market, focused on beauty, hair, body, cooling and lifestyle products.

### What the project demonstrates

- Shopify storefront management
- Product listings and collection organization
- Product imagery and merchandising
- Mobile-first ecommerce UX
- Ghana-market positioning
- MTN Mobile Money / Paystack checkout messaging
- Shipping, returns and customer-trust communication

**Live store:** [presuraaf.shop](https://presuraaf.shop/)

---

## Valenor — Fit-First Menswear Storefront

Valenor is an interactive menswear ecommerce portfolio project built around a fit-first shopping concept. Instead of forcing shoppers to browse an oversized catalog, the storefront lets them select their size and preferred fit, then presents relevant products and recommendations.

### What the project demonstrates

- Ecommerce storefront UX
- Product-page and collection structure
- Responsive web design
- Interactive size and fit selection
- Product discovery and quick-add interactions
- Capsule/character-based shopping
- Wardrobe-gap recommendations
- HTML, CSS and JavaScript implementation

**Project files:** [`/valenor`](./valenor/)

When GitHub Pages is enabled for this repository, the interactive demo is available at:

`https://alexabbou9-tech.github.io/SITES-PROJECT/valenor/`
